# Review-driven addition, October 4 KST

This addendum supersedes DESIGN.md's initial Naive Bayes architecture and single-screen sequence. The preserved NLP v001 is not used. v002 is a trained TF-IDF/softmax model with openly poor generalization (independent authored synthetic supported examples: 13/30 raw, 26 deferred, 3/4 non-deferred correct; OOD10/10 deferred). The weights and threshold remain frozen after that assessment. Do not claim a reliable language interpreter.

The primary learning experiment now fits a power-law regression from 3–10 positive numeric observations: log(y) = intercept + exponent*log(x). This is actual parameter learning from user-selected data, not a hard-coded answer. No separate probe is accessed during fitting. A separate unseen input value tests the frozen prediction. Training residual and probe error are displayed as different quantities; neither implies generalization. Default example points are synthetic. The 20% comparison tolerance is a fixed pedagogical comparison threshold, not a statistical confidence interval.

Order: header/intro -> Discover a relationship (fit-data workspace) -> the existing confirm-your-meaning system experiment -> How it works -> footer. The original visual tokens, two-column open layout, control typography, responsive collapse and accessibility table remain. Numeric fields are bounded; empty/invalid values and a probe reused from fitting data refuse testing. Editing fit data invalidates both model and probe; editing probe clears its old test only. Both core workflows have local Markdown exports. No network/model download/accounts/credits or generated image concept.
